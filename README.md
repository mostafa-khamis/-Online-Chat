# Online Chat Application

**Idea:** A real-time chat application that enables seamless communication between users.

**Key Features:**
- Implemented real-time messaging using WebSocket.
- Managed data storage and retrieval with MongoDB.
- Integrated Mongo Express for easy database monitoring.
- Designed a user-friendly interface for smooth interaction.
- Containerized using Docker for scalable deployment.

**Tech Stack:** Java, Spring Framework, WebSocket, MongoDB, Docker
